منصة تحليل النتائج التعليمية
مدارس المشكاة الأهلية بالدمام — إدارة التوجيه الطلابي

طريقة الرفع على GitHub Pages:

1- فك ضغط الملف بالكامل.
2- افتح مجلد النسخة المحدثة.
3- ارفع جميع الملفات والمجلدات إلى جذر مستودع GitHub الحالي.
4- وافق على استبدال الملفات القديمة.
5- من Settings ثم Pages اختر GitHub Actions.
6- انتظر انتهاء النشر.
7- افتح الموقع واضغط Ctrl + F5 لتحديث التصميم.

مهم:
- يجب رفع مجلد assets لأنه يحتوي على شعارات المدرسة والتوجيه الطلابي.
- لا ترفع ملفات نتائج الطلاب إلى GitHub.
- تتم معالجة ملفات Excel داخل جهاز المستخدم فقط.
- يفضل استخدام Google Chrome أو Microsoft Edge.

تحديث الجداول الذكية: تُخفى مستويات التحصيل الصفرية تلقائيًا، وتُذكر في القراءة التحليلية.
